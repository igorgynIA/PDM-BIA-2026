# PDM-BIA-2026

Trabalho final da disciplina de **Processamento de Dados Massivos**. O objetivo é desenvolver um pipeline completo de dados e aplicar práticas de **MLOps** em um projeto de **Big Data**, utilizando a **Google Cloud Platform (GCP)** como infraestrutura de nuvem.

## Parte 1 - Pipeline de dados e arquitetura Medallion

Nesta etapa, será implementado o pipeline de dados seguindo a **arquitetura Medallion**, com a evolução dos dados pelas camadas Bronze, Prata e Ouro.

### Checklist

- **Camada Bronze:** ingestão e armazenamento dos dados brutos, preservando o formato e o conteúdo originais.
- **Camada Prata:** limpeza, padronização, validação e transformação dos dados.
- **Camada Ouro:** disponibilização dos dados agregados e enriquecidos para análises, visualizações e modelos de Machine Learning.
- **Slides:** elaboração da apresentação com a arquitetura, as tecnologias utilizadas, as etapas do pipeline e os resultados obtidos.
